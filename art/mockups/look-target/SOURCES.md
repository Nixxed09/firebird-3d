# Look-target pictures

Made 2026-11-12 with Codex CLI's built-in image generation (ChatGPT subscription, no metered call), one run per picture, prompts in `prompts/`. The prompts describe the scene only; they do not name the game or anyone.

These are NOT captures of the game. Nothing in them is built. They exist so a person can pick the direction in the Game Studio (Firebird, department "Game look"). The pick becomes the target a real level is compared with.

| look_a_night_fire.png | A: city burning at night, blue and orange, wet cobbles |
| look_b_ash_dawn.png | B: the morning after, grey dawn, falling ash |
| look_c_golden_bold.png | C: golden daylight, bold colour, strong shapes |
| look_d_old_power.png | D: domed hall, old-world machine glowing aqua, etheric enemy |
